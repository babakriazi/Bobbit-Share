# Bobbit Share

اشتراک‌گذاری سریع و زیبای فایل بین گوشی اندروید و هر دستگاهی (ویندوز، مک، اندروید، iOS) از طریق مرورگر.

## ویژگی‌ها

- انتخاب چند فایل
- ساخت QR Code + نمایش آدرس نوشتاری
- صفحه وب حرفه‌ای و واکنش‌گرا برای دانلود
- کار روی شبکه محلی (همان وای‌فای)
- UI مدرن دارک‌مود با تشخیص اندازه صفحه
- بدون نیاز به نصب برنامه روی گیرنده

## نسخه فعلی

**1.0.0**

## نحوه استفاده

1. هر دو دستگاه به یک وای‌فای وصل باشند
2. در برنامه فایل‌ها را انتخاب کنید
3. دکمه «شروع اشتراک‌گذاری» را بزنید
4. QR را اسکن کنید یا آدرس را در مرورگر ویندوز وارد کنید
5. فایل‌ها را دانلود کنید

## بیلد

GitHub Actions به صورت خودکار روی push به `main` بیلد می‌گیرد.

APK را از بخش **Actions** → آخرین workflow → Artifacts دانلود کنید.
